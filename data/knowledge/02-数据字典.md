# 数据字典

数据库共 15 张业务表。以下为表与关键字段说明。

## app_config（系统配置：限流阈值、审核窗口、缓存 TTL、文件上限等可运行期调整的键值）
约 22 行数据。字段：
- id bigint：主键
- config_key varchar(50)：配置键
- config_value varchar(500)：配置值
- create_time datetime：创建时间
- update_time datetime：更新时间

## audit_log（审计日志：登录/接取/审核/结算/封禁/下架等关键操作）
约 121 行数据。字段：
- id bigint：主键
- user_id bigint：用户 id
- action varchar(50)：操作类型标识
- target_type varchar(30)：目标类型
- target_id bigint：目标 id
- detail varchar(500)：明细描述
- ip varchar(45)：来源 IP（敏感，仅管理员可见）（敏感，查询结果会脱敏）
- create_time datetime：创建时间

## claim_status_log（接取状态变更留痕：from->to/操作人/原因）
约 19 行数据。字段：
- id bigint：主键
- claim_id bigint：接取记录 id
- from_status varchar(20)：变更前状态
- to_status varchar(20)：变更后状态
- operator_id bigint：操作人 user id
- reason varchar(500)：原因/理由
- create_time datetime：创建时间

## file（文件元数据：凭证图/头像，storage_key 唯一、随机文件名，含大小与 MIME）
约 4 行数据。字段：
- id bigint：主键
- storage_key varchar(255)：biz/{type}/{yyyyMM}/{uuid}.ext
- url varchar(255)：访问地址
- size bigint：文件大小（字节）
- mime varchar(100)：MIME 类型
- uploader_id bigint：上传者 user id
- sec_status tinyint(1)：内容安全状态 0=待检测 1=通过 2=违规
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## flyway_schema_history（（系统表）Flyway 数据库迁移历史，非业务数据）
约 8 行数据。字段：
- installed_rank int：（系统列）Flyway 安装序号
- version varchar(50)：乐观锁版本号
- description varchar(200)：任务描述（<=2000 字）
- type varchar(20)：类型标识
- script varchar(1000)：—
- checksum int：（系统列）迁移校验和
- installed_by varchar(100)：—
- installed_on timestamp：—
- execution_time int：—
- success tinyint(1)：（系统列）是否成功

## login_log（登录记录：成功与否、失败原因、来源 IP（风控与审计基础））
约 92 行数据。字段：
- id bigint：主键
- user_id bigint：用户 id
- ip varchar(45)：来源 IP（敏感，仅管理员可见）（敏感，查询结果会脱敏）
- user_agent varchar(255)：—
- success tinyint(1)：（系统列）是否成功
- fail_reason varchar(100)：—
- create_time datetime：创建时间

## notification（站内通知：类型/标题/内容/关联业务 id/是否已读）
约 11 行数据。字段：
- id bigint：主键
- user_id bigint：用户 id
- type varchar(30)：类型标识
- title varchar(100)：任务标题（<=50 字）
- content varchar(500)：文本内容
- biz_id bigint：关联业务 id
- is_read tinyint(1)：是否已读（0/1）
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## report（举报工单：举报人/目标/原因/处理状态与处理人）
约 3 行数据。字段：
- id bigint：主键
- reporter_id bigint：举报人 user id
- target_type varchar(30)：task/claim/review/user
- target_id bigint：目标 id
- reason varchar(500)：原因/理由
- status tinyint(1)：0=待处理 1=已处理 2=驳回
- handler_id bigint：处理人（管理员）user id
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## review（互评记录：接取双方 1-5 分评价（claim+from+to 唯一防重复））
约 1 行数据。字段：
- id bigint：主键
- claim_id bigint：接取记录 id
- from_user_id bigint：评价发起人 user id
- to_user_id bigint：被评价人 user id
- score tinyint：1-5
- content varchar(500)：文本内容
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## settlement（结算记录：金额快照与结算时间（MVP 只跑状态位，不做真实打款））
约 1 行数据。字段：
- id bigint：主键
- claim_id bigint：接取记录 id
- task_id bigint：任务 id
- user_id bigint：用户 id
- amount decimal(10,2)：金额
- status tinyint(1)：0=待结算 1=已结算
- settle_time datetime：结算时间
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## task（任务主表：发布者发布的任务，含赏金/名额/接取与完成双截止时间/状态/乐观锁）
约 8 行数据。字段：
- id bigint：主键
- publisher_id bigint：发布者 user_id
- title varchar(50)：标题 ≤50
- description varchar(2000)：描述 ≤2000
- reward decimal(10,2)：报酬
- quota int：名额
- claimed_count int：已接取数
- claim_deadline datetime：接取截止
- deadline datetime：完成截止
- status varchar(20)：OPEN/IN_PROGRESS/REVIEWING/SETTLED/EXPIRED/CANCELLED
- version int：乐观锁
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## task_claim（接取记录：谁接了哪个任务，含结算快照 reward 与提交/审核时限（task+user 唯一防重复接取））
约 7 行数据。字段：
- id bigint：主键
- task_id bigint：任务 id
- user_id bigint：接取者
- status varchar(20)：CLAIMED/SUBMITTED/APPROVED/REJECTED/CANCELLED
- reward decimal(10,2)：结算快照
- submitted_at datetime：凭证提交时间
- reviewed_at datetime：审核完成时间
- review_deadline datetime：提交后48h审核截止
- review_note varchar(500)：审核备注（驳回原因）
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## task_status_log（任务状态变更留痕：from->to/操作人/原因（排查并发问题的依据））
约 9 行数据。字段：
- id bigint：主键
- task_id bigint：任务 id
- from_status varchar(20)：变更前状态
- to_status varchar(20)：变更后状态
- operator_id bigint：操作人 user id
- reason varchar(500)：原因/理由
- create_time datetime：创建时间

## task_submission（凭证提交：交付内容与图片 id 列表（审核前可覆盖，保留最新））
约 6 行数据。字段：
- id bigint：主键
- claim_id bigint：接取记录 id
- content varchar(2000)：文字凭证 ≤2000
- file_ids json：凭证图片 file.id 数组
- submit_time datetime：提交时间
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）

## user（用户表：微信登录用户，含昵称/信用分/角色/状态/账密（openid 唯一））
约 21 行数据。字段：
- id bigint：主键
- openid varchar(64)：微信 openid；注销时匿名化为 DEL_<uuid>（敏感，查询结果会脱敏）
- username varchar(40)：登录账号（唯一；微信登录自动生成或用户自填）
- unionid varchar(64)：预留（敏感，查询结果会脱敏）
- nickname varchar(30)：昵称，需内容安全检测
- password_hash varchar(128)：密码哈希（SHA-256 + 随机盐 + pepper）（敏感，查询结果会脱敏）
- avatar varchar(255)：头像 URL
- credit_score int：信用分
- role tinyint(1)：0=USER 1=ADMIN
- status tinyint(1)：0=正常 1=封禁
- register_time datetime：注册时间
- create_time datetime：创建时间
- update_time datetime：更新时间
- deleted tinyint(1)：逻辑删除（0=未删 1=已删）
