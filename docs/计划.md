## 1. 里程碑明细

### M0 · 地基（4h）— 不依赖 Key 的部分我立刻能做
- [ ] `config.py`：读 `.env`、护栏参数（行数/超时/EXPLAIN 阈值/Top-K）、模型档位
- [ ] `llm.py`：OpenAI 兼容封装 · **429/5xx 指数退避重试 3 次** · 统一异常 · **token/成本统计**（含单价表）
- [ ] `agent/executor.py`：SQLAlchemy 连接 · 只读执行 · `max_execution_time` · 行数上限 · **敏感列脱敏黑名单**
- [ ] `.gitattributes`（统一 LF）+ `.streamlit/config.toml` + `loguru` 日志
- **产出**：能跑 `python -c "from llm import chat; print(chat('hi'))"`；执行器能安全跑一条 SELECT
- **验收**：写操作被拒（`UPDATE`/`DROP` 报错）、`openid` 列不出现在结果里、429 能自动重试

### M1 · Schema 抽取与检索（5h）
- [ ] `data/schema.json`：14 张表 + 全部列（类型/可空/索引）+ **中文业务描述**（自动抽取 + 我补语义）
- [ ] `agent/schema_index.py`：表/列描述 → BGE-small-zh 向量 → FAISS；`--build` 建索引
- [ ] Top-K 表检索（默认 K=5）+ 检索命中日志
- **产出**：问"被封禁用户有多少"→ 命中 `user` 表；问"接取数"→ 命中 `task_claim`
- **验收**：**Schema 召回率 ≥ 90%**（用 30 条问题抽样验证，参考表在 Top-5 内）

### M2 · NL2SQL + 三层护栏 + 回环修复（8h）★核心
- [ ] `agent/nl2sql.py`：提示词（few-shot + 只读硬约束 + JSON 输出）→ 生成 SQL
- [ ] **护栏①** `sqlglot` 静态校验：仅 SELECT/WITH · **表白名单** · 禁多语句 · 强制 LIMIT
- [ ] **护栏②** 沙箱：只读账号 + `SET SESSION TRANSACTION READ ONLY` + `max_execution_time`
- [ ] **护栏③** `EXPLAIN` 预估扫描行数 → 超阈值拒绝（防大表全扫）
- [ ] **回环自修复**：0 行 / 报错 → 错误 + Schema 回灌 → 重试 1 次
- **产出**：10 个真实问题跑通（含 2 个陷阱题被拦）
- **验收**：SQL 可执行率 ≥ 95%；**首次修复成功率 ≥ 60%**；危险语句拦截 10/10

### M3 · 知识库 RAG + 意图路由（6h）
- [ ] `docs/` 业务文档（API/状态机/规则）→ 切分（chunk 300 / overlap 50）→ BGE → FAISS
- [ ] **混合检索**：向量 + BM25 → RRF 融合 → 带引用回答
- [ ] `agent/router.py`：闲聊 / 查知识 / 查数据 三分类（LLM + 规则兜底）
- **验收**：库内问题答对且**给出来源**；库外问题**如实说资料不足**（不编）

### M4 · 自动图表 + Streamlit 界面（6h）
- [ ] `agent/chart.py`：按结果形状选图（时间→折线 / 分类→柱状 / 占比→饼图）+ 中文字体
- [ ] `app.py`：输入框 · 答案气泡 · **SQL 折叠面板** · 结果表（st.dataframe）· 图表 · 引用来源 · **耗时/成本/token 面板** · 清空按钮
- **验收**：端到端演示顺畅；每个回答都能看到 SQL 与成本

### M5 · 评估集 + 跑分 + 消融（8h）★最大区分点
- [ ] `eval/cases.yaml`：**60 条**（单表聚合 20 / JOIN 15 / 时间分组 15 / **陷阱 10**），每条含参考 SQL（**在 DB 实测过**）
- [ ] `eval/run_eval.py`：**执行准确率 EX**（结果集比对：排序无关 + 数值容差）+ 可执行率 + 延迟 P50/P95 + 成本 + badcase 分类导出
- [ ] `eval/ablation.py`：关 Schema 检索 / 关回环 / 关混合检索 / 关重排 → EX 对比表
- **验收**：**EX ≥ 85%**、P95 ≤ 3s、单次 ≤ ¥0.01、消融表能证明每个模块的增益

### M6 · 部署与交付（5h）
- [ ] 部署 Streamlit Community Cloud / HF Spaces（Secrets 存 Key）+ 公开链接
- [ ] README 补**真实指标表**与消融图；`docs/报告.md`（问题定义→方案→实验→结果→展望）
- [ ] **3 分钟演示视频** + **面试讲稿**（6 步带数字）
- **验收**：陌生人打开链接能问出正确结果
