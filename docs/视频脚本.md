> 录制前：`streamlit run app.py` 已启动；另开一标签页打开 `docs/评估报告.md`

## 录制要点
- **不念稿**，卡壳就重录这一段（分段录再拼）
- 用侧边栏「示例问题」一键填入，避免手打错字
- 陷阱题演示**放慢语速**（评委最关心）
- 工具：`Win+G`（Xbox Game Bar）或 OBS，1080p 足够
- 导出后自检：**不要展开 Secrets 面板**，避免泄露 Key

## 备用：LLM 请求失败时
- 检查网络到 `api.commandcode.ai`；临时改用 `Qwen/Qwen3.8-Flash`（实测 6.1s）
- 也可以**故意展示一次失败 + 回环自修复**，这是加分项（证明系统能自愈）
