# 部署指南

## 0. 两种数据后端（先理解这个，部署方式就清楚了）

| 后端 | 用途 | 配置 | 说明 |
|---|---|---|---|
| **mysql** | 完整评估 / 本地开发 | `DB_BACKEND=mysql` + `DB_*` | 指向 WSL 里的 treatbord 库（真实数据） |
| **sqlite** | **公开演示** | `DB_BACKEND=sqlite` + `SQLITE_PATH=data/snapshot.sqlite` | 随仓库分发的**脱敏快照**，云端零依赖可跑 |

快照由 `python scripts/export_snapshot.py` 生成（14 表 / 325 行 / 84KB），自动把
`openid` / `unionid` / `password_hash` / `ip` 替换为演示值 —— **公开仓库不泄露真实数据**。
只读保证不变：SQLite 用 `PRAGMA query_only=ON`，写操作同样被拒。

## 1. 路线对比

| 路线 | 成本 | 难度 | 适合 |
|---|---|---|---|
| **① Streamlit Community Cloud + SQLite 快照**（推荐） | 免费 | ★ | 面试给链接、可交互 |
| ② Hugging Face Spaces + SQLite 快照 | 免费 | ★★ | 同上，海外访问更稳 |
| ③ 云服务器 + Docker + 真 MySQL | ¥60+/月 | ★★★ | 想跑真实库、要 7×24 |

## 2. 路线①：Streamlit Community Cloud（推荐）

**你需要做的（约 10 分钟）**：
1. GitHub 新建**空仓库**（例如 `data-agent`），不要初始化 README
2. 推送本地仓库：
   ```bash
   cd ~/Project/agent
   git remote add origin https://github.com/<你的用户名>/data-agent.git
   git push -u origin main
   ```
3. 打开 https://share.streamlit.io → GitHub 登录 → **New app**
   - Repository: `<你的用户名>/data-agent` ｜ Branch: `main` ｜ Main file path: **`app.py`**
4. **Advanced settings → Secrets** 粘贴（不要写进仓库）：
   ```toml
   LLM_API_KEY = "你的 Command Code Key"
   LLM_BASE_URL = "https://api.commandcode.ai/provider/v1"
   LLM_MODEL = "deepseek/deepseek-v4.1-flash"
   DB_BACKEND = "sqlite"
   SQLITE_PATH = "data/snapshot.sqlite"
   SQL_MAX_ROWS = "200"
   SQL_TIMEOUT_MS = "3000"
   SCHEMA_TOP_K = "5"
   ```
   > 代码已支持 `st.secrets`（`config._load_streamlit_secrets()`），无需改代码
5. Deploy → 得到公开链接 `https://<app>.streamlit.app` ✅

**注意事项**
- 公开演示会花你的 API 额度（单次约 ¥0.006）→ 平台后台设消费上限
- 演示库仅 325 行，**别拿它跑完整评估集**（评估集是 MySQL 方言，本地跑）
- 被刷量风险：Cloud 有资源限额；更严可加「每日提问上限」计数

## 3. 路线②：Hugging Face Spaces
1. 新建 Space → SDK 选 **Streamlit** → 上传/连接仓库
2. **Settings → Repository secrets** 填同样的键值
3. HF 要求 README 头部 YAML：`sdk: streamlit` / `app_file: app.py`

## 4. 路线③：云服务器 + Docker + 真 MySQL
```bash
docker build -t data-agent .
docker run -d --name data-agent -p 8501:8501 \
  -e LLM_API_KEY=... -e LLM_BASE_URL=... -e LLM_MODEL=... \
  -e DB_BACKEND=mysql -e DB_HOST=<内网地址> -e DB_USER=agent_ro -e DB_PASSWORD=... \
  -e DB_NAME=treatbord data-agent
```
**必须加固**：只读账号（`sql/readonly_user.sql`）、DB 内网可达、Nginx 限流、
调小 `SQL_MAX_ROWS`/`SQL_TIMEOUT_MS`、加访问日志。

## 4.5 依赖分层（重要，云端安装失败就出在这里）

| 文件 | 用途 | 说明 |
|---|---|---|
| **`requirements.txt`** | **云端运行时**（Streamlit Cloud 读它） | 只含轻量必需项（streamlit/openai/pandas/sqlglot…），实测干净环境 **24 秒**装完 |
| `requirements-vector.txt` | 可选：本地向量检索 | 追加 `sentence-transformers` + `faiss-cpu`（含 torch CPU，约 1GB）→ **云端免费版不建议装** |
| `requirements-dev.txt` | 开发/测试 | 追加 `pytest` |

> ⚠️ 踩坑记录：最初把 `sentence-transformers`（拉 torch）放在 `requirements.txt` 里，
> Streamlit Cloud 直接报 **Error installing requirements**（安装超时/超限）。
> 代码本身对缺失的向量库做了**可选降级**（自动退回 BM25），因此云端无需安装它们。

## 5. 部署前自检
```bash
cd ~/Project/agent && . .venv/bin/activate
python scripts/export_snapshot.py                  # 快照必须已脱敏
python scripts/smoke_sqlite.py                     # 快照后端可用（只读/拦截/脱敏）
python -m pytest tests/ -q                         # 73 项全绿
git status --short                                 # .env / .venv 不应出现在待提交列表
```
